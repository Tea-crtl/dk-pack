# dk-pack

ImHex patterns for parsing and exploring 2Moons/Dekaron file formats.

This repository contains patterns that define the data structures of various Dekaron files, making them easier to inspect and reverse engineer with [ImHex](https://github.com/WerWolv/ImHex).

## Usage

1. Open a Dekaron file in ImHex.
2. Load the corresponding pattern from this repository.
3. Apply the pattern to inspect the file's structures.

Patterns may be incomplete or version-specific.
